``pyamplitude`` is a Python client for current Amplitude Analytics APIs with an
offline-first test strategy.

It covers Dashboard REST queries, zipped event exports, Behavioral Cohorts,
HTTP V2 ingestion, Batch uploads and optional Redshift helper queries.
